# Vision dataset

Add images under `visual/aprovada`, `visual/reprovada`, `termica/aprovada`, or `termica/reprovada`, or list them in `labels.csv` with columns `path,label,modality,group_id`.

Use the same group_id for all views of one physical specimen, including across modalities. Do not move or change files under data/raw/imagens. Augmented copies are not independent specimens.
